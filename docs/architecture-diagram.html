Multi-Environment Azure Infrastructure Architecture

Production-grade, modular Terraform deployment showcasing 3-tier perimeter defense, strict lateral movement restrictions, isolated Dev & Prod environments, and unified key/state governance.

Perimeter & Inter-Tier Network Security Group Rules Matrix

Every subnet is bound to a dedicated NSG enforcing strict positive security models (default deny). Lateral movement between non-adjacent tiers (e.g., Web directly to DB) is completely forbidden by dropping packets via Priority 4096 before Azure default AllowVnetInBound kicks in.

DevSecOps & Governance Design

  • Zero-Trust Default Deny: Overrides default cloud permissiveness by blocking untracked inbound traffic at priority 4096.
  • State & Secret Isolation: Dev and Prod environments maintain separate state storage accounts and Key Vaults.
  • Global Uniqueness: Alphanumeric 6-character random entropy suffixes prevent naming collisions across Azure.
  • Mandatory Tagging: Enforces Environment, ManagedBy="Terraform", and Project tags.

Azure for Students & Cost Control

  • $0.00 Idle Cost: Virtual Networks, Subnets, and NSGs incur zero hourly provisioning fees in Azure.
  • Free-Tier State Storage: Standard_LRS Storage Accounts consume fractions of a cent unless petabytes are stored.
  • Standard Key Vault: Standard SKU avoids costly HSM / dedicated hardware modules while offering enterprise encryption.
  • Zero Expensive Gateways: No NAT Gateways, App Gateways, or Azure Firewalls provisioned by default.
